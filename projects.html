At 10xScale.ai

Domain-specialized medical agent

Private
Role owner Stack AgentFlow · FastAPI · SSE · Qdrant

Problem

Need a conversational medical agent that follows skill-specific playbooks and takes real actions — not open-ended chat.

What I built

  • StateGraph + ToolNode agent with per-skill playbooks loaded at runtime (triage, booking, medication guidance).
  • FastAPI service with SSE-streamed responses; checkpointer for short-term context; Qdrant for cross-session memory.
  • Transactional tools: doctor availability, appointment booking, structured DB queries.

Decision

Runtime playbooks over a monolithic prompt — skills stay swappable without redeploying the whole graph.

Voice-enabled edge medical kiosk

Private
Role end-to-end owner Stack Raspberry Pi 5 · PySide6 · FastAPI · Twilio

Problem

Kiosk-side voice assistant that must feel responsive in Indic languages while staying wired to the same agent backend.

What I built

  • Async VAD → STT → Agent → TTS pipeline on Pi 5 with per-turn language auto-detection across 11 Indic languages.
  • Integrated backend APIs, agent service, web app, and desktop app into one production path.
  • WhatsApp via Twilio: inbound PDF/image extraction with Gemini Vision; outbound consultation summaries.
~70% barge-in latency ↓ (1000→300 ms) 11 Indic languages

Decision

Flush OS audio buffer on stop-TTS and chunk TTS at the first sentence — barge-in felt broken until both landed.
