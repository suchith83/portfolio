# Portfolio Thumbnail Image Prompts

Generate each image at **1200×720 px** (aspect ratio 5:3).
Save as PNG with the exact filename shown.
Drop all images into: `portfolio/assets/images/`

## Style guide (apply to every prompt)

> Off-white background (#F8F5F0), warm terracotta accent (#B5483A) used sparingly on one focal element.
> Flat editorial illustration style — clean lines, generous whitespace.
> No gradients, no neon, no glow effects, no 3D renders, no faces or people.
> Feels like a New Yorker tech column header or a thoughtful Stripe blog illustration.
> Simple, bold, single focal element. Typography allowed if integral to concept.
